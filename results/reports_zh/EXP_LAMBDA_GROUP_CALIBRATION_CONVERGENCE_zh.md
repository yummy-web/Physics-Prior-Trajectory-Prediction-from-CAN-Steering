# MLP 收敛敏感性检查（因果分组 λ 校准实验）

## 目的与原则

本检查重放冻结结果中的 3 个 outer fold × 4 个 subset seed 清单，并在同一次当前代码运行内只改变 MLP 的 `max_iter`。数据、因果特征、物理先验、模型结构、随机种子、早停参数、分组切分和统计单位均保持不变；每个 test route/scene 内的重复评估先平均，再做组级比较。

- 当前代码基线：comma `max_iter=250`，nuScenes `max_iter=300`；
- higher 条件：两个平台均为 `max_iter=1000`；
- 早停：`early_stopping=True`、`tol=1e-4`、`n_iter_no_change=10`；
- 严格受控比较是当前代码基线与高迭代条件；历史冻结 JSON 仅作快照审计。
- 由于历史结果记录的脚本 SHA 与当前开源脚本不一致，本文不声称当前代码逐数值复现历史快照。

逐数值核对通过：`False`。该核对只用于披露历史脚本快照与当前开源代码之间的版本差异，不参与受控敏感性结论。

## 解释边界

1. 当前代码基线与 higher 条件的比较只说明结果对所检查 `max_iter` 范围的敏感性，不证明神经网络优化达到全局最优。
2. 历史冻结主结果与当前代码基线不是严格受控的一对，二者不得用于归因 `max_iter` 的效果。
3. `warning` 与 `hit_max_iter` 只反映 sklearn 训练停止诊断；早停会在达到 patience 时停止，因此 `n_iter < max_iter` 不必然表示损失已完全收敛。
4. comma 与 nuScenes 仍按各自平台的 route/scene 统计单位解释，不将窗口数当作独立样本。
