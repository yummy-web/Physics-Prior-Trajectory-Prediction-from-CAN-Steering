# MLP 收敛敏感性检查（因果分组 λ 校准实验）

## 目的与原则

本检查只改变 MLP 的 `max_iter`，不改变数据、因果特征、物理先验、模型结构、随机种子、早停参数、分组切分或统计单位。脚本重放 canonical 结果中的 3 个 outer fold × 4 个 subset seed 清单，并将每个 test route/scene 内的重复评估先平均，再做组级比较。

- canonical 条件：comma `max_iter=250`，nuScenes `max_iter=300`；
- higher 条件：两个平台均为 `max_iter=1000`；
- 早停：`early_stopping=True`、`tol=1e-4`、`n_iter_no_change=10`；
- 高迭代结果是敏感性证据，不自动替换 canonical 结果。

## 解释边界

1. 如果 higher 条件下收缩增益的方向、量级和组级区间与 canonical 基本一致，可将结论描述为对 MLP 停止条件具有敏感性稳定性；这不等于证明神经网络优化已达到全局最优。
2. 如果某个 N 的差异明显或方向翻转，应以 higher 结果重新评估该预算的主张，不选择性保留较有利条件。
3. `warning` 与 `hit_max_iter` 只反映 sklearn 训练停止诊断；早停会在达到 patience 时停止，因此 `n_iter < max_iter` 不必然表示损失已完全收敛。
4. comma 与 nuScenes 仍按各自平台的 route/scene 统计单位解释，不将窗口数当作独立样本。
