# CRISAL 七采集实验决策记录

生成依据：`crisal_grouped_external_results.json`、`crisal_grouped_per_acquisition.csv`、`CRISAL_GROUPED_QC_zh.md`。本文件只记录实验解释与后续安排，不修改论文正文。

## 1. 实验状态

- 7 个 ZIP 均通过官方文件大小、MD5 和 ZIP 完整性核验。
- 7 个 `.bag` 均已解压，解压字节数与归档清单一致。
- 7 个采集均通过统一 QC，最少有效因果锚点门槛为 80。
- 正式协议为 leave-one-acquisition-out：每折 4 个采集拟合、2 个采集验证、1 个采集测试。
- 每个外层测试采集包含 15 个验证组合和 3 个模型 seed，共 315 个配置评估。
- 统计单位为采集；重叠锚点、验证组合和模型 seed 均未作为独立样本。
- MLP 收敛警告数为 0。

## 2. 主要结果

采集级宏平均 FDE（单位：m）：

| 方法 | 1 s | 2 s | 3 s |
|---|---:|---:|---:|
| INS velocity ZOH | 0.335 | 1.251 | 2.655 |
| CTRV fitted steering gain | 0.351 | 1.150 | 2.438 |
| Full residual, λ=1 | 0.327 | 1.128 | 2.425 |
| Validation λ | 0.327 | 1.128 | 2.425 |
| κ=0.5（验证采集数单位） | 0.328 | 1.127 | 2.421 |

相对满残差 `λ=1`：

- INS velocity 在 2 s 的 FDE 高约 0.123 m，采集级 95% bootstrap CI 为 [0.062, 0.183]；
- INS velocity 在 3 s 的 FDE 高约 0.230 m，采集级 95% bootstrap CI 为 [0.112, 0.352]；
- 满残差在 3 s 上优于 INS 的采集数为 6/7；
- κ=0.5 在 3 s 上相对满残差改善约 0.003 m，采集级 95% bootstrap CI 为 [-0.007, -0.001]；
- validation λ 与满残差几乎相同，3 s 差值约 0.000 m。

## 3. 结果支持的结论

本实验支持以下有限结论：

1. 在同一辆 Renault Zoe、同一天的 7 次 CRISAL 采集中，跨采集拟合的残差模型在 2–3 s 预测上平均优于 INS velocity ZOH；3 s 的平均优势约为 0.230 m。
2. 残差模型在跨采集测试时没有表现出系统性失效，说明该 CAN/INS 条件下存在一定的跨采集可迁移性。
3. 在该外部协议和较高的训练预算下，验证集估计的 λ 接近 1，说明残差在此处接近全量信任；收缩带来的增益很小。
4. κ=0.5 的微小 3 s 改善可以作为稳定性/轻量风险控制的描述性结果，但不能作为 CRISAL 上的主要方法增益。

## 4. 不能支持的结论

- 不能据此声称 λ 收缩在 CRISAL 上普遍提高精度。
- 不能据此声称跨车型、跨平台或跨传感器系统泛化。
- 不能把七次采集当作七个完全独立的车辆或数据集；它们来自同日、同一辆 Renault Zoe。
- 不能把 INSPVA 当作独立定位真值；误差是相对于融合导航参考的条件误差。
- 不能把 κ=0.5 解释为普适最优超参数。

## 5. 对论文实验定位的建议

CRISAL 最合适的定位是“同车多采集的时间外部验证与运行条件异质性检查”，而不是 λ 收缩定律的主要确认性证据。论文中可以将其用于说明：

- 主实验中观察到的残差收益并非只来自单一时间片；
- 跨采集训练的残差模型在 2–3 s 上仍能超过物理基线；
- λ 的作用依赖训练预算和运行条件：在 CRISAL 的跨采集较高预算协议下 λ 接近 1，而在主实验的稀缺预算下收缩价值更明显。

最后一条是跨实验的解释，需要在正文中明确说明协议和数据源不同，不能把两者合并为一个统一的普适规律。

## 6. 后续安排

1. CRISAL 下载与 grouped 实验到此完成，不再需要为该实验线继续下载其他 CRISAL 采集。
2. 暂不下载 7V-Scenario 09；它不会直接修复 CRISAL 的同车同日限制，也不是当前 grouped 结果的必要组成部分。
3. 进入论文重构前，建议只做结果审计型补充：核对表格、图和主张是否使用采集级统计；不再为了寻找更大的 λ 增益而反复调 κ 或挑选采集。
4. 论文重构时，CRISAL 应作为外部支持证据和限制性验证，不应承担“跨平台确认 λ 收缩普适有效”的主张。
